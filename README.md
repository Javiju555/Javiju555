# Javier Juana Pradel

I build desktop tools and AI agents, mostly in Rust. Almost everything here is
something I use every day — that is usually why it got written.

## Public projects

- **[Buscador](https://github.com/Javiju555/Buscador)** — Spotlight-style launcher for Windows and Linux: app, command and file search, local ONNX semantic search, inline calculator.
- **[calculadora](https://github.com/Javiju555/calculadora)** — Desktop calculator built with Tauri and Rust: scientific mode, unit conversions, graphing and a small CAS.
- **[fenix-hub](https://github.com/Javiju555/fenix-hub)** — Ephemeral LAN clipboard across Linux, Windows and Android.
- **[mk](https://github.com/Javiju555/mk)** — Cross-platform CLI for keyboard, mouse and screenshot automation.

## In progress

- **Blazer** — an agent platform: one core with memory and skills behind a web UI, a terminal client, and a client/server split so the model can run on one machine and be driven from another. AGPL-v3; the repository goes public at launch.
- **FenixPad** — a tab-oriented multimodal editor and document suite. Closed source, with an open extension SDK planned.

Projects live under [Fenix Motion Systems](https://fenixmotionsystems.com) — a
portfolio umbrella for my work, not a company.
