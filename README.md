# Javier Juana Pradel

I build desktop tools and AI agents, mostly in Rust. Almost everything here is
something I use every day — that is usually why it got written.

### Tools

| | |
|---|---|
| **[mk](https://github.com/FenixMotionSystems/mk)** | Cross-platform CLI to automate typing, keys, mouse and screenshots on Linux, Windows and macOS — built so AI agents can drive a desktop too. |
| **[fenix-hub](https://github.com/FenixMotionSystems/fenix-hub)** | Ephemeral clipboard and file sharing across Linux, Windows and Android, over your LAN and never through the cloud. |
| **[Buscador](https://github.com/Javiju555/Buscador)** | Spotlight-style launcher for Windows and Linux: apps, commands and files, with local ONNX semantic search. |
| **[miy-joy](https://github.com/Javiju555/miy-joy)** | Lightweight GTK4 game controller tester for Linux, in the spirit of `joy.cpl`: axes, buttons, hat, touchpad and rumble in real time. |

### For fun

| | |
|---|---|
| **[IE-repack](https://github.com/Javiju555/IE-repack)** | Applies the Spanish fan translations of Inazuma Eleven (3DS) to your own Japanese dump and gives you a game ready for Azahar. No ROMs included. |
